# Social Attack

Sistema de criação e gestão de criativos para redes sociais com IA integrada.

## Stack

- React 19 + TypeScript
- Tailwind CSS v3
- Vite v6
- Supabase (PostgreSQL)
- Claude API + Gemini API
- React Router DOM v7

## Setup

```bash
npm install
npm run dev
```

## Variáveis de Ambiente

Crie um arquivo `.env` na raiz com:

```
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
VITE_ANTHROPIC_API_KEY=
VITE_GEMINI_API_KEY=
```
